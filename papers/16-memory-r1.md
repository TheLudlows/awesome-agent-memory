# Memory-R1：通过强化学习提升大语言模型智能体管理和利用记忆的能力

**英文题名：** Memory-R1: Enhancing Large Language Model Agents to Manage and Utilize Memories via Reinforcement Learning

**版本与时间：** 2025 预印本；2026 ACL Long Papers  
**主题：** 学习记忆策略  
**原文入口：** [主文](https://aclanthology.org/2026.acl-long.583/) · [arXiv](https://arxiv.org/abs/2508.19828)  
**核对日期：** 2026-10-23  
**阅读依据：** [正文或技术版本](https://aclanthology.org/2026.acl-long.583.pdf)；涉及补充稿的内容单独说明。本文为首版通俗解析，不包含独立实验复现。文中的教学例子与“本文推论”不是论文原始实验。

## 一句话理解

给档案管理员和答题助手做训练：前者学习何时新增、改写或删除信息，后者学习面对一堆候选记忆时该看哪些。[1]

## 为什么需要学习策略

手写规则很难覆盖事实重复、局部更新、无关信息和互相冲突等情况。让模型输出 ADD、UPDATE 并不代表它能一直选对，Memory-R1 尝试通过结果奖励改善决策。

## 两个 Agent

**Memory Manager** 接收新信息和相关旧记忆，选择 ADD、UPDATE、DELETE 或 NOOP。**Answer Agent** 在候选记忆中预选相关条目，再推理回答。论文使用 PPO 与 GRPO 等强化学习方法微调策略。[1，§3]

这与 Reflexion 有关键区别：Reflexion 通过文字教训改变下次上下文；Memory-R1 在训练阶段实际优化模型策略参数。记忆内容仍保存在外部，并不是把全部用户事实训练进权重。

## 教学例子：什么时候该更新

旧记忆是“用户住北京”；新信息是“现在搬到成都”。正确更新通常有助于回答“现在住哪里”。

但如果新信息是“明年可能搬到成都”，直接覆盖当前居住地就会出错。管理策略要学会区分计划、猜测和已发生的事实。

## 实验说明什么

ACL 版报告使用少量训练 QA，评估不同问题类别，并扩展到 LoCoMo、MSC、LongMemEval 及不同模型规模。[1] 作者结果说明学习策略具有潜力，不代表少量样本足以覆盖所有业务领域；训练质量、奖励和分布变化仍然重要。

## 对基础设施的启示（本文推论）

把“选择哪个记忆操作”与“如何可靠执行该操作”分开。训练好的策略只能提出操作意图，底层仍需校验权限、对象版本及约束。奖励也不能只看短期答对：保留来源、避免误删、控制成本，可能需要独立约束。
