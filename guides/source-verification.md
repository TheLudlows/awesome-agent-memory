## 需要明确的差别

- **TOIS 综述**：期刊题名为 *A Survey on the Memory Mechanism of Large Language Model-based Agents*。arXiv 2404.13501 早期题名的 Model based 没有连字符，属于同一工作。ACM 页面此次直接读取遇到 403，题名与 DOI 结合公开索引和作者项目资料交叉核对；正文解析依据可读取的 arXiv v1，不能当成对期刊版所有修订的逐项审计。
- **CoALA**：OpenReview 页面此次要求浏览器验证，使用 arXiv PDF 核对正文；PDF 首页标有 TMLR 2024 及相同 OpenReview ID。
- **Hindsight**：本清单主文是 ACL 2026 演示论文 *Hindsight: Structured Agent Memory that Retains, Recalls, and Reflects*。arXiv 2512.12818 的长稿题名为 *Hindsight is 20/20: Building Agent Memory that Retains, Recalls, and Reflects*。正文中涉及长稿机制时明确列为补充，不额外计作第 20 篇。
- **MemoryArena**：主文完整标题是 *Benchmarking Agent Memory in Interdependent Multi-Session Agentic Tasks*，不强行加上 MemoryArena 前缀。
- **LightMem**：对应 arXiv 2510.18866 和给定 ICLR 2026 页面，不能与另一篇使用 LightMem 名称的小模型记忆工作混淆。
- **A-Mem**：正式页面使用 A-Mem，早期稿中也出现 A-MEM。这里指同一篇 2502.12110，不是其他名为 Agentic Memory 的工作。
- **Reflexion**：Verbal Reinforcement Learning 在方法上不更新模型权重。参考译名使用“通过语言反馈改进”，并在正文说明原题术语，避免误读成标准梯度强化学习。
- **Memory-R1**：ACL 正式版扩展了初始预印本的实验范围；本条以 ACL 正式稿为主，不将不同版本的数值混合。

## 解析范围与证据边界

这是基于原文方法、实验描述和正式元数据的首版通俗讲解，不是全部公式推导、源码审计或实验复现。部分解析依据带版本的早期技术稿，已在各页标明。未做跨版本逐行差异检查，因此不声称覆盖每个正式版的全部修改。

每篇包含原创教学例子，并把面向基础设施的分析标为“本文推论”。实验部分概述论文评估对象与结论边界，不提供无配置支撑的最新 SOTA 排名。
